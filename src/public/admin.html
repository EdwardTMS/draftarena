1 Verifica stanza precedente

Inserisci il codice della stanza della stagione scorsa per vedere cosa è disponibile.

2 Scarica backup asta

Scarica il file di backup con tutte le squadre e i parametri dell'asta della stagione precedente. Salvalo sul tuo PC, poi caricalo nella sezione "Importa backup" qui sotto.

3 Importa Albo d'Oro

Copia tutti i backup storici, le classifiche trofei e gli alias delle squadre dalla stanza vecchia a questa. I backup già esistenti non verranno duplicati.

📦 Backup Asta

Esporta backup completo

Scarica un file JSON con tutte le squadre, rose e parametri dell'asta. Conservalo sul tuo PC per riutilizzarlo l'anno prossimo.

"Salva nello Storico" carica il backup sul server così sarà visibile nella pagina Rose.

Importa backup (nuovo anno)

Carica un backup dell'anno precedente per ritrovare subito squadre e parametri già impostati. Le rose vengono azzerate, il budget ripristinato al valore iniziale.

"Ripristina Asta Completa" ricostruisce l'asta esattamente come conclusa: budget finali, rose compilate, giocatori venduti e svincolati, stato in pausa.
